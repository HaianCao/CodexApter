# Code of conduct

CodexApter is a small open-source project. Everyone who takes part — in issues,
pull requests, discussions or reviews — is expected to help keep it a
welcoming, respectful place.

## Expected behaviour

- Be kind and patient, and assume good intent.
- Give and accept constructive feedback about code and ideas, not people.
- Keep discussions on topic and share credit for others' work.
- Respect people's time: include the details needed to reproduce a problem.

## Unacceptable behaviour

- Harassment, insults, or discriminatory jokes and language.
- Personal or political attacks, trolling, or deliberate disruption.
- Publishing someone's private information, or anyone's API keys, without
  permission.
- Sexualised language or imagery, and any other conduct that is not
  appropriate in a professional setting.

## Reporting and enforcement

Report a problem privately to the maintainer through the repository's
**Security → Report a vulnerability** form (it is private) or the contact on
the maintainer's GitHub profile. Reports are handled confidentially. The
maintainer may edit or remove comments, commits and issues, or block
participants, who do not follow this code of conduct.

This code applies in all project spaces and when someone represents the project
elsewhere. It is inspired by the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
